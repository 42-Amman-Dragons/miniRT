# miniRT scenes

These focused fixtures cover the mandatory miniRT rendering checks.

| Rendering check | Scene |
| --- | --- |
| Sphere at `{0, 0, 0}` | `01_sphere_origin.rt` |
| Plane with `z = 0` | `02_plane_z_zero.rt` |
| Cylinder along the y axis | `03_cylinder_y_axis.rt` |
| Sphere translated parallel to the camera | `04_sphere_translation.rt` |
| Cylinder rotated 90 degrees around z | `05_cylinder_rotation_z90.rt` |
| Intersecting sphere and cylinder | `06_intersecting_objects.rt` |
| Repeated spheres and cylinders | `07_repeated_objects.rt` |
| Camera on the x axis | `08_camera_x_axis.rt` |
| Camera on the y axis | `09_camera_y_axis.rt` |
| Camera on the z axis | `10_camera_z_axis.rt` |
| Camera at a non-axis position | `11_camera_off_axis.rt` |
| Side-lit sphere at the origin | `12_side_lit_sphere.rt` |
| Side-lit translated sphere | `13_side_lit_translated_sphere.rt` |
| Sphere casting a shadow on a plane | `14_sphere_shadow.rt` |
| Complex scene with several shadows | `15_complex_shadows.rt` |
| Zero-height cylinder rendered as a disk | `16_zero_height_disk.rt` |
